# Prolonge le Live – overlay TikTok

Bandeau « Prolonge le Live » : **1 pièce = +1 sec**, **1 follow = +10 sec**.

- `prolonge-le-live.png` : image à fond transparent, prête à mettre sur le live.
- `prolonge-le-live.html` + `piece-tiktok.png` : la source de l'image (pour la modifier).

## Ajouter sur le live
- **TikTok LIVE Studio** : Ajouter une source > Image > choisis `prolonge-le-live.png`.
- **OBS** : Source > Image > choisis `prolonge-le-live.png`.
